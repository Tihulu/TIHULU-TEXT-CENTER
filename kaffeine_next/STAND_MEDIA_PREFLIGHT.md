## Exact immutable candidate file inventory

Companion **[STAND_MEDIA_FILE_MIGRATION_INVENTORY.json](./STAND_MEDIA_FILE_MIGRATION_INVENTORY.json)** is a 246-record, **per-file path + Git blob SHA-1 + byte length + non-destructive candidate action** manifest derived from the complete, untruncated Git tree at original #67 head. It lists **80 `tv_center/**` blobs**, **35 `kaffeine_next/**` blobs** (including the player SVG, installer, native Qt/C++ patch sources, radio/TV/media/recorder headers), **all 20 `textcenter/**` blobs**, and **all 111 `tests/**` blobs** (92 Media-related candidate tests by filename). The Text records are explicitly `EXCLUDE_TEXT_CENTER` except four marked `REFACTOR_MUST_NOT_COPY_TEXT_PACKAGE`; tests are classified to select/review, not blindly import. It is an **inventory**, not an executed copy, approved target layout, or file transfer. Source archives and original commits remain in the origin.

**Four Text implementation dependencies to carve out, not vendor wholesale:** `textcenter/compute.py` (device/backend/languages), `textcenter/speech.py` (PCM transcribe and speaker pipeline), `textcenter/transcripts.py` (offline translation + installed pairs), and transitively `textcenter/core.py` (`Store`, text sanitation, timestamps). The last three are tightly connected, not an isolated `LANGUAGES` constant; Text's own implementation imports `tv_center` back. Direct Media import sites include `tv_center/__main__.py`, `captions.py`, `media_ai.py`, `ai_diagnostics.py`, `model_market.py`, `translation_worker.py`, `settings_ui.py`, `performance_lab.py`, `cuda_faster_whisper.py` and `kaffeine_next/captions_overlay.py`. An isolated Media checkout without `textcenter/` cannot provide the complete current ASR/translation path. Refactor to Media-owned versioned interfaces and keep Text canonical; the exact resulting code must have new owner approval.

## Exact non-destructive file/data migration contract

1. **Freeze** original Media #67 SHA, all sibling fixes #91/#96/#99 (each stacked independently), pinned KDE upstream, 246 blob identities, version stamps and package dependencies. No app code transferred now.
2. **Discover** existing `~/.local/share/tihulu-kaffeine`, `~/.local/opt/tihulu-kaffeine`, Kaffeine native `~/.local/share/tihulu-media-center`, `~/.config/tihulu-media-centerrc`, and `~/.config/tihulu-tv-center` + `~/.local/share/tihulu-tv-center` only with user consent, no following symlinks, no deleting files. Use QSettings to enumerate actual OS-native settings, do not guess Windows/macOS path from Linux.
3. **Per-item migration decision**: app-owned settings/config + models are copied or reindexed only after verifying canonical ownership, file type, size, source/destination SHA-256 and owner approval. Store under a new **Media-only namespace** on a versioned installation; create a mapping for user-editable custom paths (including external SSD), never alter foreign Text/other-app trees. Running Python venv / compiled Whisper engines should be rebuilt from pinned dependencies, not byte-moved; existing model weights remain unchanged. Missing/foreign marker/symlink = SKIP/ASK, not automatic takeover.
4. **Data protection**: retain legacy originals and all user WAV, TS, MKV, MP4, SRT, TXT, LRC, DVB recordings, export folders, channels, database, independent stock Kaffeine, custom icons/PNG and licenses. PR #96's sidecar rollback is unmerged and must be separately reviewed. Never uninstall/delete another app or a model shared by custom user path.
5. **Atomic update / rollback design (NOT IMPLEMENTED)**: stage versioned app prefix + per-architecture signed/hash-verified package; validate dependency closure in clean VM; snapshot only Media-owned settings/manifest with SHA-256; switch **owned** desktop entry/link to new version atomically; rollback restores previous binary/link/settings exact bytes, preserves any newly recorded media and older models; never update the origin repo symlink or system services generically. Explicit uninstall removes only a verified owned installation root and stops only owned children.
