**Prepared:** 2026-11-12 | **Status:** Six user-triggered agent handoffs PREPARED, not executing in background | **Owner requirement:** [RQ-098 / EXIT-01](./OWNER_REQUIREMENT_FULL_SHUTDOWN_MEMORY_VRAM_RELEASE.md) | **Central coordination:** [Issue #75](https://github.com/Tihulu/TIHULU-TEXT-CENTER/issues/75)

## Objective and proof boundary

When the user selects a genuine **Quit / Stop application** command, every worker/process/model/context/device lease owned by that application must close. CPU model allocations, GPU/VRAM contexts (CUDA/ROCm/Metal/DirectML), NPU/Hailo resources, streaming/caption queues, transient files, local endpoints and owned RF tuner leases must be released after bounded shutdown. **Do not** destroy downloaded weights, source recordings, exports, unrelated third-party apps, external `readsb/tar1090`, a paired remote GPU host or other users' model sessions.

Stop Module and full Quit are separate: module stop releases only its own lease, full Quit ends all app-owned processes regardless of Background/Always-On preference. Qt window hide-to-tray is **not** true Quit, and PWA tab close cannot guarantee native cleanup. Never claim literal system RAM/VRAM 0 MB; verify **zero app-owned sessions and OS processes**; driver caches and other processes may remain.

Source base and new Draft PR must be recorded. Do not merge, deploy, modify workflows/installers/logos/Pages, download models, run real GPU/NPU/SDR, stop host services, inspect private user files, publish release or change current user installation. New mocked unit tests must run in GitHub CI, with outcomes and expected failures described truthfully. Cross-app task ownership is constrained to the listed subtrees/repo, with no cross-worker file edits.
