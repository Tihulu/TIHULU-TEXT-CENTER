## Preservation and failure risks
1. **P0 — Wrong source-baseline import:** copied `apps/text-center/source/` snapshot is *not* an exact copy of present `main` for 3 Python backend paths. Avoid overwriting main, rebase, cherry-pick, or merging historical branches from this audit. Enumerate semantic diffs and select a reviewed later baseline with owner authorization.
2. **P0 — False TV/RF implementation claims:** the retained Text Center backend's DVB `diagnose_dvb` is passive, while actual TV playback is a delegated MPEG-TS relay. Import pages are not verified off-air Teletext. Spectrum surveys do not decode services. Preserve distinctions between passive detect, synthetic test, source implementation, actually tuned receiver, and released behavior.
3. **P0 — Contention:** FM module lock is cooperative and process discovery best-effort, not a universal SDR/DVB lease. Never stop third-party readsb/gqrx/welle/TV services on audit.
4. **P0 — Rename/Pages regression:** main workflow is scheduled every 15 minutes and hardcodes `gh-pages/flight_radar/` and old repo URL. Main README includes raw installer links to old feature branches. Existing `gh-pages` root is a multi-app portal, not proof of a Text Center PWA deployment. Exact deployed URLs, base paths, icons, caching and redirects must be measured independently.
5. **P1 — Localization/inventory honesty:** only `<html lang="en">` and current English UI observed in retained code; the `LOCALIZATION_CONTRACT.json` declares en/tr/de as future. NOAA/AIS/ACARS/RTL-433 module presence was *not* substantiated; a decoder executable check is not a decode result. Avoid claiming missing source from this app means no history exists elsewhere.
6. **P1 — Original history portability:** copy only permalinks, immutable IDs, source refs and legally/permissibly exportable metadata; do not fabricate native reviews or publish private chats.
