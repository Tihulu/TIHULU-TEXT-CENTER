Satellite Center Direct browser WebUSB · experimental

Track ISS, Meteor-M, CubeSat and Iridium NEXT on interactive OpenStreetMap Earth and azimuth/elevation sky maps using CelesTrak orbital elements. The Chromium WebUSB mode can request direct RTL-SDR access and save raw IQ. The optional local companion supports external APRS/SatDump decoding and longer-lived scheduled captures. Iridium remains orbit/spectrum survey only, not private communications decoding.

  • No local software needed for browser mode when a supported Chromium browser can claim your RTL-SDR via WebUSB. Linux/Windows may still require driver or USB permission changes.
  • Supports Debian/Ubuntu/Pop!_OS, Raspberry Pi OS, macOS Apple Silicon/Intel and Windows x64 with separately installed SDR utilities and drivers.
  • Receiver is released after Stop/Quit and on abandoned manual sessions. A single RTL-SDR is not available to Flight Radar and Satellite Center simultaneously.

To see the Satellite Center icon in Applications and Dock: open the Browser-only app in Chrome/Brave/Edge and choose Install this site as an app, then pin it. Firefox can use the pass calendar but not direct WebUSB; for RF reception in Firefox use the optional localhost companion.

New observer location tools: select your position by explicit browser GPS permission, search 8,084 Germany/Türkiye cities offline with suggestions as you type, optionally search worldwide online, or enter any latitude/longitude manually. The Earth and Sky maps and satellite pass planner share your selection.

Standalone receiver starts at http://127.0.0.1:8791/. Copy the local pairing token from that page into the hosted Satellite Center dashboard. On Safari, prefer the local dashboard if loopback requests are restricted.

Direct WebUSB mode asks for USB permission and keeps recordings on your computer. It currently collects raw IQ and calculates orbital passes; in-browser satellite image and APRS decoding are not yet connected. Firefox/Safari are unsupported. Only the optional companion requires http://127.0.0.1:8791/ and pairing.

This website does not itself connect to USB, track you, or collect private reception data. It is not an emergency alert service.
