## 0. Decisions and hard safety boundaries

- **Target architecture:** Media-owned Python/backend package installed *with the Media application*, no `textcenter` package, Text checkout, Text HTTP server, shared AI Tools/Survival Kit/Jan daemon or remote host required. External KDE Kaffeine/libVLC/FFmpeg/welle/RTL-SDR and user-installed AI runtimes are **declared, capability-gated third-party dependencies**, not other TIHULU applications.
- **Preserve API outputs and behavior:** TV DVB subtitle descriptors, Teletext page/audio PID priority, fallback Whisper audio, TR/EN/DE/manual and auto source choice, sentence carry, 10 s adjustable buffer/one offset, real karaoke timestamps only, DAB metadata separated from speech recognition, live/export SRT/TXT/VTT/ASS/JSON/LRC, MKV/MP4 no-overwrite, selected recordings folder and local playback. No algorithm or feature removals disguised as packaging work.
- **Source ownership:** Do not vendor all of `textcenter/` or its news/RSS/HTTP/SQLite `Store`. Keep canonical Text unchanged. Extract only precisely named leaf APIs into Media-owned implementations with provenance/license review, compatible return formats, recorded errors and tests. No new source edits until separate owner approval.
- **Data ownership:** No automatic moves, uninstalls, model re-downloads, `rm -rf`, arbitrary symlink traversal, shared-cache deletion or updates to another app. Legacy user settings, original Kaffeine channels and recordings, user-selected external SSD model paths and credentials remain intact. Any future migration starts as **read-only dry run** and proceeds only with user consent and checksum verification.
- **Keep separate:** sibling [EXIT-01 #91](https://github.com/Tihulu/TIHULU-TEXT-CENTER/pull/91), [sidecar rollback #96](https://github.com/Tihulu/TIHULU-TEXT-CENTER/pull/96), [REG-16 #99](https://github.com/Tihulu/TIHULU-TEXT-CENTER/pull/99), and audit [#105](https://github.com/Tihulu/TIHULU-TEXT-CENTER/pull/105) are unmerged variants of #67. None is implicitly installed or combined. Reconcile under reviewed integration order only after approval.

### 3A. Read-only-first, crash-safe migration protocol (proposed, never run here)

1. **Inventory/ownership:** opt-in discovery for exact known files, inspect path kind with `lstat` (not follow symlinks), uid, ownership marker, bytes, SHA-256, user selected settings paths, Qt native QSettings actual backend, source/destination free space and current running app. Report `UNKNOWN`, `FOREIGN`, `SYMLINK`, `CUSTOM PATH` as SKIP/ASK rather than take ownership.
2. **Dry-run deterministic mapping:** produce a redacted plan JSON with classification `COPY`, `REBUILD RUNTIME`, `PRESERVE POINTER`, `KEEP`, `SKIP`. Do not include raw remote GPU/DeepL tokens. Never delete source; never mutate existing target; no network/model inference. Obtain explicit user choice for paths and weights.
3. **Consented copy only:** destination must be new/app-owned; create private parent (0700); open source with no symlink follow; stream-copy to unique `.partial` in same filesystem with size cap, fsync and SHA-256; verify `fstat` identity before commit; atomic no-overwrite publish using platform-correct primitive (not a vulnerable check-then-replace). Journal exact created owned targets. Preserve source timestamps/permissions where allowed and no hardlink across app ownership.
4. **Recoverable failure:** on crash or partial copy, original and all successful user files remain. Retries compare existing checksums; never replace an existing foreign destination or assume a filename grants ownership. Rollback removes **only verified migration-created** artifacts with race-safe owner identity; never recursively delete an arbitrary cache, shared model path or recording folder.
5. **Versioned update and rollback:** install isolated version, run no-device and export smoke, then change only verified Media launcher/desktop ownership to versioned target. Rollback restores prior binary/settings pointer and exact checksums without removing recordings made under new version. Legacy model dirs stay readable with explicit validated pointer until the owner elects otherwise.
6. **Uninstall:** require explicit owner decision and manifest; uninstall removes only verified installed Media binaries/cache and its owned workers after bounded shutdown. Preserve configs, models, user recordings by default; never stop foreign `readsb`, `tar1090`, `Gqrx`, system Kaffeine, welle, Ollama, Jan, Text Center or other apps.
