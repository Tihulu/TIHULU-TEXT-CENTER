No RF samples received. Reception and metadata are never simulated.

Mono FM: 87.5–108 MHz. Raw IQ: 24–1766 MHz, maximum 64 MiB per capture, saved as .cu8. DAB 11D at 222.064 MHz and ADS-B at 1090 MHz may be sampled but are NOT decoded here. Saved files are local downloads, not permanent server archives.

One Nooelec cannot receive FM and ADS-B simultaneously. If readsb/welle.io owns the device, release it in that app first. This page never kills external processes. Hiding/closing this tab requests release; unexpected crashes may prevent orderly shutdown.
