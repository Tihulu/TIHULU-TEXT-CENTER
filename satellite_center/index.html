Connect your USB SDR

Plug the Nooelec NESDR SMArt v5 into this computer's USB port, then attach the antenna cable to the dongle's SMA antenna socket. The GitHub Pages website cannot directly open USB hardware. It controls the SDR through the locally installed companion.

First-time setup · USB, local app and pairing
  1. Connect hardware: Insert the Nooelec RTL-SDR USB dongle; connect an antenna to its SMA RF connector (never connect an antenna directly to a computer's USB socket). For Meteor weather images use a ~137 MHz V-dipole/QFH; for ISS use ~145 MHz; Iridium requires an L-band antenna around 1.6 GHz, preferably with a suitable filter/LNA. Connecting an antenna does not establish reception.
  2. Install the local companion on this same computer: select the operating system below; run the installer as your normal user, then open TIHULU Satellite Center from your Applications/Start menu.
  3. Open http://127.0.0.1:8791/ on the computer holding the USB dongle. On that LOCAL page click Reveal GitHub Pages pairing token. Copy the full 64-character hexadecimal key. This is not your GitHub password, USB serial number, or an antenna identifier.
  4. Back on this GitHub Pages tab: paste the token into the field marked Pairing token and click Connect. An “Invalid token format” message means the input is not a complete 64-character key. If the connection fails, verify the companion is running locally and browser loopback permission is allowed.
  5. Check the dongle: click “Test USB receiver (temporary access)” after pairing. If readsb, Gqrx, welle.io or another SDR service is using the SAME dongle, stop it manually first (the app will not take it over).






The USB test uses the installed rtl_test program, may briefly reserve the dongle, and releases it on completion. It does not identify satellites or test the antenna. It never stops readsb automatically.

Other hardware: Hauppauge WinTV-soloHD (Amazon ASIN B0152XLPFS)

Use in the TV / DVB-T2 area, NOT for satellite SDR scanning. The Hauppauge WinTV-soloHD 01589 is a separate DVB-T/T2 and DVB-C television USB tuner. It cannot replace the Nooelec NESDR for ISS, Meteor-M, CubeSat or Iridium reception. Its ordinary TV antenna connector is not interchangeable with the Nooelec SMA input without an appropriate RF adapter, and an adapter alone does not make it a satellite antenna.
