Satellite Center No local app

Control your Nooelec RTL2832U receiver from this HTTPS page using a USB permission prompt. No Python service, pairing token or software installation for the web app itself.

Optional local companion mode · Application center
Show Satellite Center in Applications / Dock: in Chrome, Edge or Brave choose Install this site as an app from the browser menu or address bar, then pin it in your operating system's dock. The installed app uses the new radio V-dipole icon and opens its own window.

Firefox on Linux does not natively install PWAs and cannot open RTL-SDR via WebUSB. The pass planner still works in Firefox. For real SDR reception with Firefox, start the optional local companion and open the local receiver page. That requires installed helper software; a browser permission alone cannot replace WebUSB.

Browser compatibility: Chromium (Chrome/Edge/Brave/Opera), HTTPS and a free RTL-SDR are required. Firefox and Safari do not support WebUSB. Windows can still require a WinUSB driver, and Linux may need USB access permissions / the DVB kernel driver released. No website can bypass OS permissions. Web RTL-SDR library

USB not connecting? Diagnose without installing anything

A browser permission cannot stop readsb or unbind a Linux kernel driver. This diagnostic only reads WebUSB permissions; it will never claim USB, install software or change system settings.

Click Check USB permissions to inspect the browser's existing device permissions. If the device is busy, stop only the program you own before retrying.

The browser will show the USB chooser. Select the Nooelec / Realtek RTL2832U. Other applications such as readsb, Gqrx or welle.io must release the same dongle first; this page never stops them. A cancelled chooser is not a driver failure. On Pop!_OS, check the readsb service and Linux DVB driver if the USB claim fails.

3 · Satellite pass planner (web-only)

Uses downloaded CelesTrak TLEs and JavaScript orbital propagation. No local backend. If the remote catalog blocks browser CORS, import your own TLE text file below.

All location methods are optional. City suggestions are offline by default; GPS asks permission only after you click.

Offline city directory: country/state/city open data (ODbL 1.0, derivative of dr5hn). Online search uses Open-Meteo Geocoding / GeoNames (non-commercial API), only if requested. Your GPS position remains in this tab and is not sent to city search.

You can always enter fully custom latitude and longitude anywhere on Earth. Selecting a city or granting GPS permission updates both numbers, the pass planner and Earth/Sky tracking coordinates. Recalculate passes after changing ground station.

No orbit data loaded. Predictions are not RF detections.

Track ISS, Meteor-M, amateur CubeSats and Iridium from TLE orbital elements, similar to Heavens-Above pass charts. A map pin is NOT a received signal. The ground view uses OpenStreetMap; the sky view uses your manually chosen observer location. Both share the same orbital catalog as the pass planner above.

Decoder availability and truthful status

Browser-only v0.3 provides genuine USB IQ collection and geometric pass estimates; in-page APRS/SSTV/Meteor image decoding is not connected yet. Use SatDump or another decoder with the saved CU8 file where legal. Iridium remains RF-energy research only; no private communications decoding.

What requires more than a browser?

Windows may require WinUSB driver setup; Linux may require releasing the kernel DVB driver or adjusting permissions. To record a pass while the browser is closed, the optional local companion must remain running. The companion still supports offline SatDump and multimon-ng where installed.
